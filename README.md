# Zuhaib Mushtaq — QA Portfolio

This is an original, responsive QA engineering portfolio inspired by the structure and professional feel of modern QA portfolios such as markcustard.com. It is NOT a copy of that site's source code, branding, text, images, or proprietary assets.

## Files

- index.html — complete single-page site
- style.css — responsive dark UI
- script.js — navigation, portfolio filters, contact mailto and resume download
- assets/favicon.svg — favicon
- resume.pdf — add your own resume here before publishing

## Before uploading

1. Replace `your.email@example.com` in `index.html` and `script.js`.
2. Replace LinkedIn and GitHub placeholders.
3. Add your real `resume.pdf` to the root folder.
4. Replace/expand project descriptions with real work and public-safe artifacts.
5. If you want a working server-side contact form, connect the form to Formspree, Netlify Forms, or your own backend.

## Deployment

Upload the entire folder to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal static web host.
